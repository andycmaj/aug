# Botany concepts adoption

## Task types expansion

tasks are types of agent-assisted work i do

- general/to-do
- coding
- code review
- analysis
- investigation

### Triage

triage will create tasks of appropriate type from incoming activities.

### Task-specific assistance

- e.g. code review task: triage -> do prep work, estimate effort, context collection -> pass to me
- e.g. investigation task: gather context from everywhere/invoke investigation skill

## Behaviors

behaviors are tracked and weighted in order to help me get better at related @Dimensions of @Tasks that we think are objectively important to a high-functioning dev/team.

- (code review) review code thoroughly
- (code review) review code responsively
- (coding) self-review/learn my agent-generated code
- (coding) complete quiz before submitting a PR

## Dimensions

dimensions are aspects of measuring health related to Tasks. Health on Dimensions calculated by processing Activities and awarding **points** for various Behaviors.

- `participation`
- `effectiveness`
- `responsiveness`
- `thoroughness`
